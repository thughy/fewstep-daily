结论先行第一层 · 框架

本周主判断： 我们把三根旋钮从「故事」里拆出来了——而且有几条和周初直觉相反。

  1. 推理时步数分配升成正式格（F7）。 Speculative Forcing 证明：在 Self-Forcing 随机出口已经把中间 x̂0 训成合法样本的前提下，逐 token 早停可以在等吞吐下打赢均匀少步。上周还把这一格当成「放不进框架」的低优先级边角。
  2. 初始化是独立变量，常常比换散度更能动态度。 Drift Forcing（自 rollout 漂移场初始化，DMD 不动）、One-Forcing（CD 初始化把 Dynamic 从 52.76 砸到 23.61）、WorldPlay2（初始化 +7.9 vs replay +1.3）三条独立证据同向。
  3. 轴 C 多了一条省显存的路： WorldPlay2 用师生共享的压缩记忆做 clip 级打分，表内≈全上下文，每步时间约 −36%。
  4. 真实数据 / 特征监督只在高噪声段有用——Routed Forcing 是本周第三次独立确认（接 FocusOPD、DUET）。
  5. Direct Forcing ≠ Drift Forcing： 两篇摘要都报 VBench Total 84.63，一个是「漂移场初始化 + DMD」，一个是「单阶段 CCA + MMD、无 DMD」——同数字、不同机制。

对我们训练的含义：

  • 流式 AR： (a) 保留随机出口 DMD，才能白嫖 Speculative 式早停；(b) 先跑三路初始化 {ODE, CD/rCM, Drift 缩小版} × 同一套 DMD；(c) 长 rollout 打分试 {全上下文, 压缩记忆}；(d) Direct Forcing 问的是「有参考视频时还要不要 ODE→DMD 两阶段」——同底座同 4 步对照。
  • AV： Routed 的噪声路由可从 SF 检查点再训约 200 步；Lost/LiveTalk 要求参考图质检 + ODE 训够；FastH3 给出可抄的 τ_a≠τ_v + 分模态 DMD 归一。
  • 图像 / 视频： 「学生在哪些状态上被监督」（自 rollout / 先验噪声 / 混合）升为独立实验轴（CDM / StateMix / OPTD）。
  • Q3 补漏： LeapTalk 等 5 篇 S1 新漏检最高只到「值得读」，无新必读·先跑；约 30 篇 shortlist 当年没挂 F9 评级，本周补挂摘要级。

本周认知变化（按格子）第一层 · 框架

F7 × 流式：Speculative Forcing（必读·待代码）

内容
周初相信 推理早停多半打不过均匀少步（ForcingBooster 4 底座只赢 1）；「放不进框架」优先级低。
现在相信 冻结 4 步因果学生，每步中间 x̂0 当草稿，按 token 冗余度/稳定性（或 4.11M verifier）决定是否定稿；定稿 token 停去噪但留 KV；chunk 末 t=0 干净前向刷新。等吞吐下可赢均匀少步，前提是训练时随机出口已经监督过中间 x̂0。
证据 LongLive 等时 Total +0.63；Lingbot 24.5 fps / Q 82.65 / Drift 2.839 vs 均匀 3 步 22.8 / 82.38 / 3.361原文。仓库仍只有 README → 降为必读·待代码实测。
训练含义 想白嫖早停就保留随机出口 DMD；先跑训练无关 verifier vs 等墙钟（含 VAE）的均匀 2/3 步，60 s，≥2 种子。

L4 × 流式：One-Forcing（必读·先跑）

内容

现在相信 逐帧 1 步 + DMD2 + 真实数据 GAN 头（挂在 fake-score 第 21/29 层）可以冲到与 SF 4 步同量级的 headline；CD 初始化伤动态是新发现（Dynamic 23.61 vs ODE 52.76）。FFE（首块 4 步）撑起了部分 headline。
证据 VBench 83.76（含 FFE）> SF 4 步 83.46；纯 DMD 75.27；代码 Aurora-edu/One-Forcing 已核【代码】。Q3 漏因：只扫新投稿窗口，没扫旧 ID 的 replacement。

L4 × AV：Routed Forcing（必读·先跑）

内容
周初相信 动态度靠 DynaForcing 式换起点，或全局混真实视频。
现在相信 SF-DMD 第 5–6 步：非嘴部 × 高噪声时，real score 改在同噪声匹配的真实视频上算；低噪声仍 DMD。噪声路由单独就能把 RAFT 拉到 7.50（区域路由只有 6.27）。低噪声 DFD 有害——与 FocusOPD / DUET 同向，本周第三次。
证据 同协议赢 DynaForcing / Reward Forcing / DFD；RAFT 7.80 vs SF 5.62原文。无代码。Q3 漏因：标题无 distill，正则无泛化 \w+ forcing。
训练含义 从 SF 检查点只加噪声路由约 200 步；补 60 s 漂移（论文只测 ~5 s）。
