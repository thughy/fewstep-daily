Any Forcing 2610.42031 → 值得读

背景（人话）：流式自回归视频可以边出边播，但多数方法被钉在固定采样步；压到一步时画质掉、长序列还容易漂移甚至崩。

具体问题：固定步数无法在质量/速度间拧；一步采样误差沿时间轴累积。需要同一套训练同时做到「任意步可用」和「一步也稳」。

方法（逐步）：

  1. 因果学生：沿 Causal Forcing 一类因果 DiT，按时间块自回归出潜变量。
  2. 统一对抗判别器（三任务）：RA 对齐真实分布；CA 在同噪声下用停梯度的 k+1 步输出指导 k 步（跨步一致）；FE 抬第一帧质量。
  3. 训练信号：DMD（教师分数−学生分布分数）+ 对抗 + 早期 ODE 终点回归（LDMD+Ladv+λ·LODE）。
  4. 训练免费自适应长记忆：按全局语义相关 + 局部价值挑历史状态并重映射时间位置，压一步长视频漂移。

为何有效：对抗头把「要像真的」和「改步数仍要对齐」绑在同一目标；记忆筛选减少一步 rollout 错误累积。

关键数字（VBench 480p）原文：5s 配置 1* Total 85.06（One Forcing 84.35 / Causal Forcing 83.06）；1† 84.79 vs One Forcing 84.01；4 步 85.09≈Causal 85.08。30s/60s 一步亦领先 Infinity RoPE / Deep Forcing / Relax Forcing。H100 短/长约 20.9 / 24.7 FPS。

局限：完整训码/权重未见公开（PDF 仅 Project Page 字样）；「一步」仍对首帧用 4/2 步（1*/1†）；T2V 非音画；4 步几乎打平 Causal。

定级说明：Codex 按 method (b) 同协议胜 One Forcing 倾向「必读·先跑」；我方落 值得读——缺训码无法「先跑」、首帧仍多步、非 AV。认知上必须露出，不埋在「无新必读」下。

对我们：挂 流式时间轴 × L3 对抗（+L2 DMD）；与 Self / Causal / One / Direct Forcing 对照读。执行：不新开必读票（等码）。

Better Critic / STAC 2610.42135 → 值得读

背景（人话）：DMD 少步蒸馏靠「教师分数 − 评论家估的学生分数」教学生。评论家太弱或信息不对，信号会坏。

具体问题：只放大教师、评论家仍小 → 学生变差甚至坍塌；评论家若不分生成步、去拟合所有步的混合物，多步质量上不去。

方法：

  1. Joint scaling：教师与评论家同档扩容（T≈F）。
  2. STAC：评论家条件化学生生成步 k（≠加噪时刻 t），估该步专属分数；推理不加成本。

为何有效：评论家容量跟上教师才能给可靠分数差；步条件避免把不同档学生输出糊成一锅。

关键数字原文·项目页：ImageNet 纯 DMD 下 4 步 SiT-B FID 13.91→6.90（joint+STAC）。Wan2.1 4 步 1.3B：14B/1.3B 83.94 → 14B/14B 84.26 → 14B/14B+STAC 84.32。FLUX.2 亦有 HPSv3/DPG 增益。

局限：项目页明确 Code soon；主实验 T2V/T2I 非音画；相对 Self Forcing 默认 14B/1.3B 的视频增益幅度不大，但是可复用旋钮。

对我们：挂 L2 DMD 族补丁（与 IDM/sDMD 并列）。记下两条旋钮：评论家跟教师同扩、评论家加步条件。训码未开 → 不升必读·先跑、不开新票。
