详细条目（3 条）

① WorldPlay2：让 teacher 和 student 共用压缩记忆，长 rollout DMD 只给 critic 看一个 clip（值得读·流式）

它在做什么（按顺序）原文 §3.2–3.3、C.2、Alg.1

  1. 记忆：历史用低分辨率、低帧率的 VAE latent，经 TinyHistory 式卷积 + 注意力压缩成记忆 token；条件 = sink token + 相邻 chunk + 压缩历史。
  2. 初始化：把 PDD（分块预测相邻区间的平均速度）扩到带记忆的 AR 学生，得到 4 步学生。
  3. Stable Forcing：学生无梯度地完整生成整段 rollout（320 latent，切成 10 个 clip）；每个 chunk 随机缓存一个中间去噪步。
  4. 打分：对每个 clip，前面已生成的 chunk 变成记忆；real / fake score（双向 teacher，同样用压缩记忆训练过）只看「这个 clip + 记忆」。
  5. 回传：打分后用缓存的那一步带梯度重算，累计各 chunk 梯度更新一次学生；fake score 按 DMD2 更新。

因果逻辑：长 rollout DMD 的瓶颈是 critic 要吃整段上下文（显存和时间随长度涨）。如果 critic 本来就是在压缩记忆条件下训练的，那 student 和 critic 对「过去」的理解是同一种表示，打分只需 O(clip) 的上下文。代价是 critic 看不到全分辨率历史。

证据原文 表8、§4.2

变体（WBench） Avg Quality Setting Consistency
无初始化、无整段 rollout 73.9 74.4 64.6 82.6
无初始化 75.2 76.2 68.0 83.3
全上下文 teacher 82.3 81.6 79.5 89.4
完整方法 83.1 81.8 81.5 90.0

全上下文 teacher 训练 261 s/iter vs 167 s/iter，320 latent 时 OOM。表 7（重访一致性，96 latent）压缩记忆 vs 全上下文 PSNR 18.80 vs 18.47，SSIM 0.653 vs 0.688，有升有降。主表 WBench 83.1 vs Alaya-Evoke-Turbo 82.0，checkpoint 和分辨率是否对齐没写。推理 16 FPS 需要 8×H20。

和最接近工作的核心差别

  • vs Self Forcing：SF 的 critic 打分时看的是学生整段生成；WorldPlay2 把 critic 的条件换成压缩记忆、按 clip 打分。同一个 DMD loss，换了 critic 的上下文。后果：可以把 rollout 拉到 320 latent 而不 OOM。
  • vs SGF / RELIC 的 rollout–replay：「无梯度整段生成 + 随机一步带梯度重算」这部分是重做；表 8 里它单独只贡献 +1.3（73.9 → 75.2）。
  • vs 昨天的 Matrix-Game 4.0：两者都先蒸一个少步初始化再 DMD；Matrix-Game 用 CD，WorldPlay2 用 PDD。WorldPlay2 给了「无初始化」的量化代价（−7.9 Avg），Matrix-Game 没给。

为什么不是必读·先跑：仓库 WorldPlay2/WorldPlay2 只有推理（reactor/inference/pdd.py、generate.py、A14B 配置）和权重，没有训练代码，(a) 条不满足；WBench +1.1 不是同协议对最强基线，(b) 不满足【代码：我用 GitHub API 列了文件树】。

和文献同事的分歧：他判「可用资源（重做 × 存疑）」，理由是 replay 部分是 SGF 的重做、表 8 缺 init-only 行。这两点我同意；我升级的理由是表 8 第 3、4 行给出了「压缩记忆打分 ≈ 全上下文打分」这个对我们有用的对照，这是 replay 之外的那部分。流式 / WM 主评级归他，蒸馏侧评级归我。

预测：如果后续有人补 init-only 行，Stable Forcing 的 replay 增益会 < +1 Avg；压缩记忆打分会被别的长视频 DMD 工作采用。等训练代码或第二篇独立复现。

② Radian：在 AR DMD 上加冻结 DINOv2 多层特征的判别器（值得看·高）

操作原文 §3、A.5–A.6：学生 4 步 chunk 生成（Wan2.1-1.3B）；每个 rollout 随机解码 21 个 latent 里的 8 帧，梯度穿过冻结 VAE 和冻结 DINOv2-S/14；DINOv2 第 6/8/10/11 层 + patch 输入共 5 个轻量头做 hinge GAN，正样本是 40K 未公开来源的真实视频；生成器 loss = DMD + adv，权重都是 1；先 200 步只训判别器，再 600 步联合（8×B300）。

证据原文 表1/2；Codex 抽取 + 我核了 0.4995 / 0.8033 / 0.7805 / 0.8041

  • 4 步：VBench Total Self Forcing 0.8393 → Radian 0.8444；VideoAlign 0.4995 → 0.8033。
  • 1 步：VideoAlign One-Forcing 0.0448 → 0.2563。
  • 长视频：VBench-Long Rolling Forcing 0.7805（5 步）→ 0.8041（4 步）。
  • 特征空间对照：VFM GAN 比本地实现的 DiT 特征 GAN VideoAlign 高 0.37。

和最接近工作的差别

  • vs ADD：ADD 已经用冻结 DINO 特征判别器；Radian 把它搬到 AR 视频 DMD，并且是稀疏解码帧而不是整段。
  • vs DMD2 / One-Forcing：DMD2 / One-Forcing 的判别器在扩散内部特征上；Radian 的对照显示换成外部 VFM 特征后 VideoAlign 明显更高，但 VBench 只差 0.003。
  • vs Salt：同 4 步，VBench 0.8434 vs 0.8444，几乎一样。

为什么只是值得看：基线都是官方 checkpoint 重测，没有「同预算 DMD 续训」的对照，所以 +0.30 VideoAlign 里有多少来自额外 600 步训练说不清；没有人评；没有代码。预测：同预算续训对照下 VBench 差距会缩到噪声内，VideoAlign 差距会保留一部分。

③ AdvFidelity / DualHeads：少步生成器上的「判别器当 reward」（值得看；RL 侧归 RL 同事）

AdvFidelity 的关键一步原文 §3.4、Eq.4、表4：判别器 = 冻结 DINOv2-L [CLS] + MLP；正样本是参考图，负样本是把同一张参考图加噪到 t∈{0.3,0.5}，用当前生成器剩下的 1–2 步重建。这样正负样本内容、构图一样，判别器只能看伪影。生成器（FLUX.1-dev LoRA，4/8 步，无 CFG）按 LeapAlign 直接把 HPSv2 + λ·D 的梯度沿少步轨迹回传。

  • 消融（8 步 HPDv2）：+在线判别器 0.3416 → 0.3558；+目标域参考 → 0.3920；+内容对齐负样本 → 0.4125。
  • 同步数对比：8 步 HPSv2 0.4125 vs 同 8 步重训 RTDMD 0.3923；GenEval 0.7759 vs 0.7236原文 表1/2，RTDMD 是作者用官方代码重训。
  • 「先 LeapAlign 再 DMD」会把 HPSv2 从 0.4096 拉到 0.3978，作者用这个说明分阶段会吃掉 RL 收益。
  • 没有代码声明。

DualHeads原文 表1/2：reward 头 + 参考判别头都挂在冻结 teacher 特征上，生成器只回传单步重算。同 4 NFE 下 GenEval 0.90 / OCR 0.92，落后 TDM-R1 的 0.92 / 0.95；Z-Image HPSv3 13.93 vs TDM-R1 12.67，但分辨率 512² vs 1024²，不对等。论文承诺发表后放代码。

和最接近工作的差别：AdvFidelity vs Adv-GRPO：同样是在线对抗 reward，差别只在负样本是内容对齐的重建；DualHeads vs TDM-R1：不要 teacher / fake score 的轨迹匹配，只用两个二分类头，代价是同 NFE 分数更低。

对我们的含义：Radian 和 AdvFidelity 指向同一个便宜实验：如果我们给 DMD 加对抗项，负样本用「真实片段加噪 + 学生少步重建」，而不是学生从纯噪声生成的结果。推断，未实测。

① iSSFM（Improved Training of Strong Stochastic Flow Maps）：让「随机 flow map」也能用 MeanFlow 类导数 loss（值得看·高）

2610.29605，AITHYRA / TU Wien / TUM（Alexander Tong 组）。L1 轨迹 / flow map 格，图像。论文写了代码和 HF 权重链接，但 13:4x 查时 GitHub 404、HF 401（还没公开）实测。

做法，一步一步原文 §3–4：

  1. 要学的对象：SDE 的「强解映射」Ψ_{s,t}(x, W)：给定起点和同一条 Brownian 路径，一步跳到 t 时刻的样本。确定性 flow map（MeanFlow、AYF）跳的是 ODE；这里跳的是 SDE，所以网络还要吃一个噪声路径的表示。
  2. 路径怎么喂给网络：把 [s, t] 上的 Brownian 路径用平移 Legendre 多项式展开成 N 个系数（N=3），和输入拼接。对照组是 Pan et al. 的全局 KL 系数 + 一阶增量。玩具实验里只有 Legendre 能让网络真正用到一阶以上的信息原文 图3a。
  3. loss 怎么能求导：Brownian 路径处处不可导，MeanFlow / AYF 的 Eulerian（对 t 求导）loss 原本用不了。做法是 Wong–Zakai 化：用光滑的多项式路径 W^(N) 代替真实路径，SDE 变成一个可以对时间求导的随机 ODE，再套 iMF loss。Doss–Sussmann 变换版本的 1-NFE 模型完全不用系数原文 图3b。
  4. 参数化（三处改动）：指数提升（exponential lift）、Brownian 路径的闭式鞅项（Itô 积分精确算，不用数值积分）、瞬时漂移匹配（代替 SSFM 那种回归一小步 Euler–Maruyama）。没有指数提升时，闭式鞅项会发散成纯噪声原文 §4.2。
  5. 从确定性模型微调：起点是 DMF-XL/2+（Decoupled MeanFlow，本身蒸自 SiT-XL/2+REPA），加一个小 diffusion head 和 Brownian 系数输入，微调 100k iter。

为什么有效（因果逻辑）：SSFM 只能用 semigroup loss（「一大步 = 两小步」，自洽型），而确定性 flow map 的经验是导数型 loss 更强 → 难点在路径不可导 → 用光滑多项式路径 + WZ 化以后导数型 loss 可用 → 同参数化下 semigroup 换成 WZ-iMF，4 NFE FID 14.67 → 5.96，FD-DINOv2 288.1 → 143.0（相对原版 SSFM 475.1 约 3.3×）原文 表3。代价：semigroup 训出来的模型路径一致性（strong 性质）更好，iSSFM 换来的是分布指标原文 图5b。

为什么还值得留意：强随机少步映射是「少步 + Feynman–Kac 校正 / 粒子重采样」的前提（权重沿粒子自己的路径积分，必须是强解）。论文只在 40 个高斯的 2D 例子上演示了 4 NFE + FKC原文 §4.3。推断如果以后我们要在少步学生上做推理时 reward 倾斜（SMC / FK steering），这条线比「先蒸成 ODE 再加噪」更干净。迁移到 AV / 流式：目前无。代码放出后，我会核对 WZ-iMF 的目标构造。

② Attn-Forcing：在 LongLive 式长 rollout DMD 上，加「被逐出 KV 的注意力代理」和注意力匹配 loss（值得看·流式记忆）

2610.30036，没有代码链接实测：HTML 与 abs 页都没有。文献同事判「新机制(局部) × 存疑」；RL 同事也转了。

做法，一步一步原文 §3.2–3.3、Alg.1：

  1. 底座是 Self-Forcing 的因果初始化，4 步 [1000, 750, 500, 250]，frame sink 3 帧 + 局部窗口 9 帧。先做 700 步短 DMD，再按 LongLive 做 60 s streaming long tuning 2,300 步。
  2. 代理：K=3 个可学习 latent P。每次有帧被挤出局部窗口，P 就用 cross-attention 读这些被逐出的 latent，再经门控更新（Proxy Update Module）。更新后的 P 走一遍 DiT，得到逐层 KV，插在 sink 和局部 KV 之间。所以推理时每块多一次 DiT 前向，H20 上端到端多约 13%。
  3. 监督目标：用 Performer 式正随机特征（M=128）在线累加被逐出 KV 的统计量 S = Σφ(k)vᵀ、z = Σφ(k)，近似出「如果还保留全部历史，当前 query 会得到的注意力输出」Â_hist。
  4. loss：L = L_DMD + λ·MSE(A_proxy, sg(Â_hist))，只加在最后 6 层。DMD 那一项完全不变（teacher 是双向 Wan，critic 照常），注意力匹配只更新代理相关参数。
  5. 推理时不用 Â_hist；直接拿 Â_hist 生成会越来越糊原文 图5。

因果逻辑：DMD 只匹配输出分布，没有任何信号要求代理记住被逐出的内容 → 只加代理几乎没用（60 s VBench total 80.03 → 80.16）→ 加注意力级监督后到 82.37，主要是 dynamic degree 46.8 → 72.1原文 表3。
