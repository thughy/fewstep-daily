结论先行第一层 · 框架

今天的判断： 两篇新论文的标题讲的机制，都不是它们自己的消融真正支持的那个。真正起作用的是一个更朴素的旋钮，而且两个都能直接搬到我们的训练里：

  1. PMDD（data-free 多步 DMD）说增益来自「每个步数阶段单独配一个 fake score」。可它自己的消融显示：给共享 fake score 加阶段条件，FID 只变 0.05；而把「前缀输入由冻结的上一阶段学生生成，而不是由正在训练的学生生成」这一项换回去，ImageNet64 两步 FID 从 2.12 退到 8.01原文 App.D.5/D.6。也就是说，真正的旋钮是前缀样本从哪来。这和 Self-Forcing「历史必须 on-policy」的直觉正好相反，值得在流式上对照。
  2. Priming Models 完全不用教师：先在一个固定噪声级（t=0.8）上做去噪预训练，再在冻结特征空间里用 Sinkhorn OT 直接对真实图像做分布匹配，训练 25k 步。ImageNet-256 一步 FID 1.19，训练算力是 Drifting-L 的 1/6（239 vs 1476 EFLOPs）。在 5 个训练没用到的特征空间里，平均 Fréchet 距离领先更多（7.10 vs 12.59）原文 Tab.1；代码已核对 loss 链路。它说明「一步生成」不一定要走蒸馏，只要初始化对，固定特征上的分布匹配就够了。
  3. 清晨复评的 DMAD 升为必读·先跑（代码和 MiniMax-H3 AV 配置齐全）。不过它的 AV 同步分低于 DMD2（49.1 vs 56.7），所以先跑同步对照。

对我们训练的含义：

  • 流式 AR：加一组便宜对照，「历史 chunk 由当前学生 rollout」对比「历史由冻结 / EMA 快照学生 rollout」，其余全同。PMDD 在图像多步上测到的方差下降很大，AGF 的 critic 也已经在吃 replay 里的旧样本（10-16 更正）。如果冻结快照不伤长时漂移，就能省掉一部分 rollout 成本，fake score 训练也更稳推断。
  • AV：critic 选型的候选多了一个。DMAD 是「判别器 + 真实 AV 数据」，Priming 则说明「固定特征上的 OT + 真实数据」本身就够强。两者都要真实数据，也都没有测细粒度音画同步。
  • 图像 / 视频：已经蒸馏好的少步学生，可以试「几千步特征空间 Sinkhorn 后训练（对真实数据）」，和「同步数的 DMD2 GAN 头」比，量 FD-DINOv2 和 recall推断。

详细条目（2 篇新精读）

① Priming Models：不用教师的一步生成器，难点在初始化，不在 loss（必读·先跑）

关键操作（以代码为准，JaeyeonKim01/priming，2026-10-15 推送）【代码】

  1. 预训练：x_t = (1−t)·x + t·ε，t 固定为 0.8（配置里 t_min = t_max = 0.8），网络不吃时间条件，直接预测干净图 x。loss 是自适应加权的像素 MSE，加 LPIPS 和 ConvNeXt 感知 loss（configs/pretrain/_base.yaml，losses/reconstruction.py）。
  2. 后训练的输入：直接喂纯噪声 ε，一次前向得到 x = G(ε)。另取一批噪声 ε'，在 no_grad 下生成 x'（posttrain.py:42-46）。
  3. 谁给谁打分：冻结的 ConvNeXt 和 ResNet-MAE 提特征，没有可训练的判别器。每步取 16 个类，每类 64 张生成图、128 张真实图（configs/posttrain/_base.yaml）。
  4. loss：5 × [OT_ε(x, 真实) − OT_ε(x, x')]，这是 Sinkhorn 散度的代理形式：前一项把生成样本拉向真实样本，后一项让生成样本彼此推开。ε 按 0.001 / 0.01 以 3:1 混合（losses/matching.py:72-109）。
  5. 梯度怎么回去：先在特征空间求出 loss 对特征的梯度，再做一次 VJP 穿过冻结编码器回到像素，最后反传进 G（input_vjp，_SampleGradient）。lr 1e-5，batch 1024，25k 步，cfg = 1.0。 - 核心 loss 整条链已在代码里核对过：噪声 → G → 冻结特征 → Sinkhorn plan → 特征梯度 → VJP → G。✓

等价形式推断，Codex✓：一步生成器 G 在冻结特征空间里最小化它和真实数据之间的 Sinkhorn 散度，相当于核固定、不训判别器的 MMD-GAN。按我们的分类，它不属于蒸馏三条线中的任何一条（没有教师），挂在「额外真实数据」那一行。

因果逻辑：分布 loss 给出的特征梯度方向本身是对的 → 但随机初始化的网络，其参数雅可比几乎不响应这些方向，所以参数更新推不动样本 → 去噪预训练让网络先学到图像流形，雅可比在 loss 梯度的主方向上响应更强 → 后训练就快。证据：4 个预训练程度不同的模型，雅可比归一化响应越高，后训练后的 FID 越低原文 Fig.4；只有 4 个点，属于相关性证据。还有一个侧证：预训练噪声级设成 1.0（等于纯噪声，什么都学不到）时，FD-loss 版本的平均 FD 是 50.06；0.8 时是 4.95原文 Tab.9。

数字例子：Priming-L（160 轮预训练）FID 1.19，总算力 239 EFLOPs；Drifting-L FID 1.61，1476 EFLOPs。也就是用 1/6 的算力，FID 低 0.42原文 Tab.1，所有方法用同一套 torch-fidelity 重算。

② PMDD：逐阶段 data-free DMD，真正起作用的是「前缀用冻结的上一阶段学生生成」（值得读）

关键操作原文 §3，App.D

  1. 阶段 1：标准 data-free 一步 DMD（fake score 训在学生输出上，学生梯度 = fake − 教师）。
  2. 阶段 k：从噪声出发，用冻结的上一阶段学生 G_{k−1} 跑完前 k−1 步，得到 x_{t_k}（不回传梯度）。正在训练的学生 G_k 只学最后一步 x_{t_k} → x0。
  3. fake score f_k 从 f_{k−1} 初始化，在 G_k 的输出上重新训练；学生用 DMD（或 SiD）梯度更新。
  4. 「不遗忘」项：λ·‖G_k(x_{t_j}) − G_{k−1}(x_{t_j})‖²，j < k，只拿最近的上一阶段学生当参照，省显存。
  5. 推理：同一个模型，1、2、3 步都能跑。

等价形式推断，Codex✓：L2 线。每个阶段都是一次 DMD，只是「前缀样本」来自冻结策略而不是当前策略，另外加了一项向上一阶段学生的回归。

因果逻辑：当前学生在训练中一直变 → 它造出的前缀输入分布也在变 → fake score 追的是移动靶，方差大 → 换成冻结的上一阶段学生，前缀分布固定，fake score 能拟合准 → 证据：只改前缀来源，CIFAR-10 两步 FID 5.89 → 2.91，ImageNet64 8.01 → 2.12原文 App.D.5。

注意：论文的主叙事是「每阶段单独一个 fake score，消除负迁移」，还给了 Prop.1。但它自己的对照显示，给 DF-DMDv2 的共享 fake score 加阶段嵌入，FID 只变 0.05（3.27 → 3.22，2.49 → 2.44）原文 App.D.6。而「逐阶段 + 当前学生造前缀」（5.89）反而比同时训练的基线（3.27）更差。所以增益主要来自冻结前缀，不来自专门的 fake score推断，依据原文 D.5/D.6。

数字例子：头条数字「ImageNet64 两步 FID 1.99，低于 512 步教师 2.32」用的是 SiD loss。和 DF-DMDv2 用同一种 loss 时是 2.12 vs 2.49，增益 0.37，其中另有 0.13 来自换 loss原文 Tab.1b、Tab.8、D.6。

挂格

L3 判别式 × on-policy + 真实数据，轴 C 改的是「打分目标」：目标从教师换成教师和真实数据的几何混合。保持 K5 不变。Codex 盲分没做，待补。

等价 loss（推断，依据原文 Prop.1 和 App.A）

  • 判别头用 BCE 训到最优时，h = log p_target,t − log p_θ,t，所以 ∇ₓh = s_target − s_θ，正好是 DMD 梯度。生成器 loss −h 的梯度因此就是 DMD 的反向 KL 梯度。
  • 两个头配上线性损失：λ_T·KL(p_θ‖p_T) + λ_R·KL(p_θ‖p_R) = Λ·KL(p_θ‖M) + const，其中 M ∝ p_T^ρ · p_R^(1−ρ)，ρ = λ_T/Λ（原文 App.A，gap 重加权关闭时成立）。
  • 一句话：DMAD ≡「朝教师和真实数据几何混合分布做的 DMD」，score 差由密度比分类器给出，再加按噪声段的教师权重 ω（真实头判别 gap 越大的噪声段，教师权重越小）。

关键操作（以代码为准：train/wan/rcm/models/t2v_model_distill_dmad.py）

  1. 数据：Q = 预生成的教师样本（训练时不在线调用教师），T = 和 caption 配对的真实 latent（H3 用 UltraVideo 的视频和对齐音频）【代码 L12; train/h3/data_process/encode_real_videos.py】
  2. critic = fake-score 骨干（从教师权重初始化，同尺寸），最后一个 block 的 token 特征接两个 per-token MLP 头，token 取平均得到 d_real 和 d_teacher【代码 L306-342】
  3. critic 步：学生无梯度生成 G；G、Q、T 用同一个 t、各自独立的噪声加噪；loss = softplus(−d_T(Q)) + softplus(d_T(G)) + softplus(−d_R(T)) + softplus(d_R(G))。只有 BCE，没有扩散回归【代码 L437-454；L86 断言 loss_scale=0】
  4. 生成器步：critic 冻结，loss = −ω·d_T(G)/E[ω] − d_R(G)，ω = sigmoid((median_b gap − gap_band)/τ)，τ=2，gap = E[d_R(T)] − E[d_R(Q)]，按噪声段做 EMA【代码 L383-416】
  5. 更新比：Wan 配置 student_update_freq=2，即 1:1 交替【代码 configs/experiments/dmad/wan2pt1_t2v.py:49】；H3 配置 fake_update_ratio=1，学生和 critic 都训 LoRA【代码 train/h3/configs/dmad_minimax_h3.yaml:52,68,80】
  6. 论文没写的：critic 和生成器前 50% 的 block 都加了冻结增益的谱归一化（dmad_generator_spectral_norm=True，frac 0.5）代码 L63-68；原文全文搜不到 "spectral"。这很可能是 GAN 式训练能稳住的关键之一，复现时不能漏推断。

核心 loss 整条链已在代码里核对过：数据 → 加噪 → 骨干 → 双头 → BCE / 线性 loss → 更新比。✓

RepForcing

关键操作原文 §4：

  1. 数据 = Causal Forcing 第一阶段那 3K 条双向 Wan 合成视频。
  2. 学生（因果 1.3B）在加噪的 x_t 上 TF 预测干净 x̂0。
  3. x̂0 和目标 x0 分别过截断的冻结 Wan2.1-14B，取第 8 / 40 block、固定 τ、双向注意力的 token 特征，单位化后算 1 − cos，目标端 stop-gradient。梯度穿过冻结的 14B 回到学生。
  4. 然后直接进入不变的非对称 DMD（14B 教师，1.3B fake）。 等价 loss原文给出的恒等式：1 − cos = ‖Φ̄(x̂0) − Φ̄(x0)‖²/2，也就是归一化特征空间里的 L2 回归，相当于 TF 初始化用的「视频感知 loss」。逻辑：latent MSE 的最优解是后验均值，会糊 → 换成特征度量后最优解不一定是均值 → 4 步时更清晰原文 §4.1；「不一定是均值」只是论述，没有证明它收敛到哪个模式。

核心差别：

  • vs Causal Forcing：去掉了「AR 教师训练 + 因果 ODE 采集」两个阶段，换成一次 TF 特征回归；DMD 不变。
  • vs Self-Forcing：SF 的初始化用双向教师的 ODE 对（因果不单射）；RepForcing 不用 ODE，避开了单射性问题，靠的是 TF + 感知度量。
  • vs REPA / LADD：特征不是用来对齐生成器内部激活，也不当判别器，只用来度量预测和目标的距离。 疑点：基线是论文里报的数，不是重训的；DMD 阶段步数是否和 CF 一致没有直接对照；没有「同数据 latent MSE TF 初始化 → DMD」这一组，所以分不清增益来自感知度量还是来自少了一个阶段推断。

跨两篇的观察：Glance（1 条轨迹够用）和 RepForcing（不要轨迹也行）共同说明，DMD 前的初始化只要提供大致的轨迹几何和清晰度先验，规模不重要。这条挂在 baseline「L1 轨迹匹配 + 因果学生退化成条件均值」这一格的前提上，给它补了证据：初始化的作用有限，最终质量由 DMD 决定推断。

结论：评级维持「必读·先跑」（10-15 复盘时定的）。但「增益主要来自什么」要说得更窄：AGF 在 240s 只比它的底座 SGF 高 +0.75（84.82 vs 84.07）；不加正则的 AGF 是 82.75，低于 SGF。拆开看，每个部件都没有站得住的单独增益证据，最可信的是 SGF 底座本身原文 Tab.1/2 + 推断。

更正三处

  1. fake score 怎么训：干净分支和对抗分支的 X0 都 detach 后放进 replay buffer（每 rank 8 batch，各占一半）。fake score 在 5:1 中的 4/5 步里从 replay 取样，做标准扩散回归，不再新做 rollout【代码 adversarial_history_dmd.py:268-289,407,447; trainer/distillation.py:735-745】。所以对抗历史也改变了 critic 看到的分布，不只是生成器的输入。我 10-15 写的「双路 DMD」漏了这一点。critic 步省掉了 rollout，这也是整次训练成本反而更低的原因：0.86× SF，生成器单步是 SGF 的 2.0–2.3×推断，按代码算。
  2. 高斯对照：同 RMS（0.05），三项分数 71.09 / 68.60 / 75.11（5s / 60s / 240s），远低于 SF 和 SGF。0.05 RMS 的小噪声不太可能比不加扰动差这么多，更像是那次训练崩了（单次）。代码里也没有高斯分支的配置【代码 rg 无结果】。所以它不能当作「梯度选方向的价值」的证据。10-15 我说「高斯对照很可能没调好」，方向对，但应该直接说「这个对照无效」。
  3. 无正则的 82.75：这是 240s Q5 的分数，不是 5s，也不是 60s。无正则在 5s 是 81.38，60s 是 77.96，60s 低于 SF 的 79.56。完整 AGF 在 240s 比 SGF 只高 +0.75。所以 10-15 那句「增益可能主要来自正则」要改成：增益来自「对抗历史 + 首步一致性正则（只在前 200 步，权重约为 DMD 梯度的 5%）」这个组合，论文没有给「SGF + 正则」这一组。

另外两个代码细节：扰动是 L2/RMS 归一化，不是 sign，也就不是经典的 FGSM；历史用的是 exit 步的 x0 预测，不是最终的干净块【代码 :148-156; pipeline:239-242】。
