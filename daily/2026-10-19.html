Drift Forcing

Drift Forcing（OR Gffoov6YRI）· 必读·先跑（仅OR摘要 + 代码已核，v1.4 (a)）

结论先行：它把流式蒸馏的初始化阶段从「teacher forcing 下回归教师轨迹」（Causal Forcing ODE / Causal-rCM 一致性）换成「学生自 rollout 上的样本级漂移场」：在冻结因果教师的特征空间里，把学生的 4 个同 prompt rollout 拉向一条双向教师 clip、彼此推开。后面的 DMD 阶段一行不改。摘要自报：DMD trainer、数据、预算固定时，VBench Total 84.63，所有初始化里最高，领先来自 dynamic degree【仅OR摘要】。匿名代码已公开，核心 loss 链我在代码里核过【代码】。

对我们训练的含义：我们关心的动态塌缩，可能一半在初始化就定了（One-Forcing 也测到 CD 初始化 Dynamic 23.61 vs ODE 52.76）。流式学生做 DMD 前，值得把「初始化方式」当成一个独立变量来对照，而不是默认 ODE。代价是初始化约 400 H800·h，比 ODE 初始化贵。

预测（读代码前写，read-log）与结果

①相对 Causal-rCM 初始化领先 <0.5 Total；②动态度升、quality/aesthetic 降；③单种子；④无 ≥60 s 评测；⑤不做等初始化算力对照 —— 都要等全文，今天不计。 ⑥ loss 是「吸引 − 互斥」核加权位移、停梯度目标 x + V 的定点回归 → ✓【代码 field_video.py:58-90】。按格预判（L5）：带宽敏感 → 代码里视频用 4 个温度 τ∈{0.1,0.2,0.4,0.8} 相加、逐个归一化，注释写明这组是专门扫出来的，比图像版（0.02–0.2）大 5–8 倍【代码 model_drift.py:42-46】→ 带宽确实要按任务重标定（部分印证，不计）。

挂格

初始化阶段：L5 样本级漂移场 × on-policy（学生 4 步自 rollout）；之后 L2 DMD（SF 标准）。Codex 盲分：「L5 drifting → 之后 L2，顺序而非同时的 L4；只改初始化；循环内只用到第 2 步 rollout 和第 7 步 loss」——和我一致Codex✓。

关键操作（以代码为准，anonymous.4open.science/r/DF0E51）

  1. 每个 prompt 让学生用产品调度（4 步）自 rollout G=4 条，梯度沿用 SF 的截断（每个 chunk 只有最后一步去噪带梯度）（model_drift.py:325-347，drift_n_gen=4）
  2. 把 rollout 加噪到 t=0.1，冻结的因果教师跑一次，在 block [1,7,15,23]（1.3B）上挂 hook 取特征，默认对所有 token 做均值池化（第二阶段改为按 chunk 池化）；梯度穿过教师回到学生【代码 model_drift.py:41,51-52,358-359】
  3. 正样本 = 该 prompt 的一条双向教师 clip（来自公开的 Causal-rCM 合成训练集），特征无梯度
  4. 漂移场（field_video.py:kde_block_loss，自称逐行移植官方 drifting 代码）：距离按批内平均距离归一化；logit = [−d(g,pos)/τ, −d(g,g)/τ]，权重 a = √(softmax_行·softmax_列)；吸引 t_att = (a_p·Σa_n)·pos，互斥 t_rep = (a_n·Σa_p)·g；V = Σ_τ (t_att − t_rep)/rms
  5. loss = MSE(g·c, sg[g·c + V])，即把特征推一步 V【代码 L88】
  6. 之后加载这个初始化，跑标准 SF DMD：real = Wan2.1-T2V-14B，CFG 3，LR 2e-6 / 4e-7，5:1，1000 步，batch 64【代码 drift_dmd_vidprom64.yaml】

因果逻辑

因为 ODE / CD 初始化只在真实前缀上学单条轨迹 → 学生第一次看到自己的前缀是在 DMD 阶段，而 DMD 的反向 KL 偏向低运动模式 → 静态的初始化会被 DMD 进一步锁死。漂移场在自 rollout 上训练，而且同 prompt 的 4 条样本互相排斥 → 初始化就保留了「多样、会动」的样本 → 证据：领先来自 dynamic degree【仅OR摘要】；One-Forcing 的 CD vs ODE 初始化动态差 29 个点原文 2605.23458。 数字例子：G=4 时，互斥项让每条 rollout 被另外 3 条推开，吸引项只有 1 个正样本——如果 4 条都塌到同一个静态解，互斥力最大，loss 不可能为零。

  • 等价形式（推断）：把 SF 的 DMD 推广为一族「历史 × 视野」视图：每个视图规定条件历史（零历史 = 全局视图；学生生成的历史 = 局部视图）和视野长度，在加噪历史条件下比较加噪视野的分布。全视频匹配是特例。改的是第 5 步（打分看什么上下文）。
  • 摘要里的三条结论：①边际一致时，目标分解为覆盖度加权的自回归条件散度之和，只要覆盖度为正，零点和全序列匹配相同；②干净历史分布固定时，前缀匹配和条件视野匹配梯度相同；③前缀匹配与受限全视频匹配的 score 差可以不一致 → 选哪种时间视图会改变指导方向。

3. Eviction Is Not Forgetting / ARROW（SzwzEvDIQ7）· 必读候选（仅OR摘要，免训练）

  • 发现：KV 写入那次前向会读当前缓存，所以每个新条目都存了旧条目的「拷贝」；旧块被窗口淘汰后拷贝还在。L 层、窗口 W 时，一次缓存差异最多持续 L·W 次写入，而不是 W 次。
  • 操作：去噪时读完整缓存（read long）；写入时只用上一块和当前块的干净 latent 重新编码，不读旧 K/V（write local），只存当前块的 K/V。免训练，多存一个 latent 块。

  • 按这一格预判它会在哪里出问题：训练时缓存是「读旧缓存写入」的，推理改成局部写入会造成训练-推理不一致 → 短视频（<10 s）可能略降，长视频才赚。

1. MDD：Modality-decoupled DMD（H3ndlmRluy）· 必读候选（仅OR摘要）

  • 发现：两个模态偏好的再加噪尺度不同；共用一个 fake-score 目标时，总 loss 看起来正常，其中一个模态却欠拟合。
  • 操作（推断的等价形式）：DMD 梯度里 x_τ 的加噪改为 x_τ = (x_v 加 τ_v 噪声, x_a 加 τ_a 噪声)，τ_v、τ_a 各自从自己的分布里采样；「保持 in-distribution 的联合模型评估」应该是指教师在训练时见过模态各自 t 的输入（LTX-2 训练本身就有分模态的 σ，见 vllm-omni 的 _VideoAudioScheduler）。fake score 的去噪 loss 也按分支在各自的 τ 上算，而不是一个联合 MSE。
  • 和最接近的工作比：Decoupled DMD 2511.22677 把 CA 项和 DM 项的 τ 分开（按项解耦）；MDD 把模态的 τ 分开（按模态解耦）。两者可以叠加，形成 2×2 的 τ 表。OmniForcing / DMAD 是 AV 流式 DMD，但目标对两个模态是对称的。
  • 预测（读全文前写，北京时间 07:4x）：①最佳 τ_a 分布比视频的更偏低噪声（音频局部结构细，高噪声时打分信号弱，和 MAAD 的 Fisher 论证同方向）；②两项改动分开消融，fake score 分支化的贡献 < 分开加噪的贡献；③不报嘴型 / 同步指标（只报 VBench + CLAP），或同步指标基本不变；④单种子、只有 LTX-2.3 一个底座；⑤不做流式 / 因果。按格预判（L2 两模态解耦）：两模态各自对齐边缘分布，但联合分布（同步）没有额外约束，同步可能变差。

2. MAAD：Horses for Courses（GpT7BPei8K）· 必读候选（仅OR摘要）

  • 发现（理论）：在高斯数据上做 Fisher 信息分析，再加噪会让「跨时间相关」的信息以 O(ρ_τ²) 衰减，一阶统计量只以 O(ρ_τ) 衰减。所以音频里弱的长程依赖拿到的分布梯度很小，容易被 fake score 的偏差淹没。教师再加噪诊断显示，同 SNR 下音频比视频丢的结构多。
  • 操作：①目标解耦：音频和视频不用同一个 DM 目标（具体形式摘要没说）；②异步去噪：音频 token 远少于视频，在视频步之间插入只跑音频的子步，复用视觉 KV 缓存，额外算力 6%；③SCTA：教师的音频速度在学生的（detach）视觉缓存下计算，而不是在教师自己生成的视觉上下文下计算，消除「目标的视觉上下文 ≠ 学生的视觉上下文」这一跨模态条件错配。
  • 为什么重要：③是 K1 在 AV 里的对应物：K1 说双向教师看整段 → 打因果学生有错配；SCTA 说教师看的跨模态条件要和学生一致。这是「打分侧条件来自学生」的又一个独立证据。②直接给出一种非对称步数的 AV 学生，和我们的步数预算决策相关。
  • 预测：①理论只在高斯数据上，没有对真实音频 latent 验证 ρ² 衰减的拟合；②去掉 SCTA 的消融损失 > 去掉异步子步的损失；③只在歌唱 / 音乐任务上评测，不报语音（WER）或说话人 avatar 嘴型同步；④对比方法里没有 MDD 这类「分模态加噪」的简单基线；⑤视频指标基本持平或略降（资源都给了音频）；⑥单种子。按格预判（L1+L2、条件来自学生）：学生视觉早期质量差时，SCTA 给的音频目标会跟着视觉错误走（音频和坏视频对齐），需要视觉先收敛或加 warm-up。
